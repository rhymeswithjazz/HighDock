# HighDock 0.4.2

- Recognize a saved setup after reconnecting when macOS chooses a different main display. Exact layout matches take priority, and ambiguous matches leave Dock settings unchanged.
- Refresh saved setups when the setup window opens or becomes active and when displays change, so changes saved by another running copy do not leave a setup marked "Unsaved setup" or "Not connected".
- Preserve unsaved edits to a selected setup when refreshing an unchanged display layout.

Requires macOS 26 or later. Supports Apple Silicon and Intel Macs.
