# HighDock 0.1.1

A cleaner settings window with native grouped controls and more room for your setups.

- Refined spacing, typography, and the display preview.
- Kept Save and Apply visible at the bottom of the window.
- Replaced the trash icon with a clear Delete Setup button and a confirmation that names the setup.
- Increased the window height and hid the settings scroll indicator.
- Moved Launch at Login into a General section.

Requires macOS 26 or later. Supports Apple Silicon and Intel Macs.
