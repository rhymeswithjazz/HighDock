# HighDock 0.1.0

HighDock remembers Dock position and auto-hide for each monitor layout. Resize the Dock normally; its size and other settings stay under your control.

- Save setups for your laptop and external displays.
- Switch automatically when the monitor layout changes.
- Pause switching or make temporary changes through macOS.
- Receive signed updates through the menu bar.

Requires macOS 26 or later. Supports Apple Silicon and Intel Macs. Install HighDock in Applications before enabling Launch at Login.
