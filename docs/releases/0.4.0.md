# HighDock 0.4.0

Each saved setup can now turn the Dock's show and hide animation on or off.

- Use “Animate Dock show and hide” below the auto-hide setting.
- Restore the setup's custom animation timing when turning animation back on.
- Keep the initial show delay unchanged.
- Leave animation timing unchanged for older setups until the new control is edited.

Requires macOS 26 or later. Supports Apple Silicon and Intel Macs.
