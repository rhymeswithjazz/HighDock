# HighDock 0.2.0

Choose a main display for each saved setup to help place the Dock on the monitor you want.

- Added a Main display picker with numbers that match the monitor preview.
- Remember the selected display when a saved layout reconnects.
- Keep recognizing the setup after its main display changes.
- Preserve relative monitor positions and mirroring when applying the choice.

Choosing a monitor changes the Mac's main display. macOS still controls Dock placement on shared edges. Existing setups keep the current main display until you choose one.

Requires macOS 26 or later. Supports Apple Silicon and Intel Macs.
